# Required adjustments for 0.0.21

Upgrade from 0.0.20. The logging/timing changes below are based on the branch diff
against `master`; earlier lifecycle changes are covered by the 0.0.20 notes.

## Required migrations

- Replace `pookiepy.logger` imports with `jacl4py.logger`. Import `JacLogger`
  instead of `GrpcLogger`; `get_logger`, `INTERNAL_INFO` and `INTERNAL_DEBUG`
  retain their names. The local logger module is removed.
- Replace `pookiepy.timer` imports with `simpytick.timer`. `TimedEvent` and
  low-level `timer` retain their argument names. The local timer module and its
  compensation helpers are removed; use the package directly.
- `logger.setLevel(...)` now changes only the logger threshold. To preserve old
  handler-level changes, call `handler.setLevel(...)` for each `logger.handlers`
  entry, or configure output levels through `get_logger` before first use.
- `get_logger(log_dir=None)` now disables file output. Omit `log_dir` or pass
  `LogDir.DEFAULT` for temporary files. Update log collectors: default files are
  `%TEMP%/<safe-name><uuid8>/<safe-name>.log`, not `grpcLogs/<name>_YYYYMMDD.log`.
  Daily rotation keeps up to 30 backups per writer; old run directories remain.
- Package loggers have a separate registry and do not replace Python's global
  logger class. Use `jacl4py.logger.get_logger`, not `logging.getLogger`, when
  retrieving a client's/server's logger or using `iinfo`/`idebug`.
- Timers no longer change process priority. Compensation uses a persistent
  monotonic schedule instead of digit-based correction; periods must be finite
  and positive, counts must be integers with `n >= 0` or `n == -1`, and booleans
  are rejected. Invalid arguments raise `TypeError` or `ValueError` before startup.
- Background timer failures now raise `RuntimeError` during iteration or normal
  context exit. Handle them where timer contexts run. First ticks remain immediate;
  slow consumers may still miss ticks. Keep process creation in guarded importable
  scripts; use `backend="thread"` after starting gRPC threads to avoid child creation.

## Optional configuration

- Pass an application-owned directory to `get_logger(log_dir=...)` for durable
  logs; each writer gets a unique filename in that directory.
- `reinit_if_exists=True` replaces a cached logger. Use the returned object;
  deleted/replaced logger references are no longer usable.

Installing pookiepy installs `jacl4py>=0.0.1` and `SimPyTick>=0.0.2` automatically.
Client/server hooks, routing and protobuf interfaces are unchanged by this refactor.
